# Tree-Plantation-Website
ExploreIt is a frontend web project focused on environmental awareness and sustainability.
The project encourages users to participate in activities like tree plantation, recycling, and nature conservation.
## Features
* Responsive UI
* Tree plantation awareness pages
* Recycling information section
* Login & Signup pages
* AI Plant Suggestion Assistant
* Animations and glassmorphism design
* Event registration system
## Technologies Used
* HTML
* CSS
* JavaScript
## Project Pages
* Home Page
* Plantation Event
* Recycling Page
* Clean Air Page
* Save Nature Page
* Better Future Page
* Login & Signup
## Purpose of Project
This project was created to spread awareness about protecting nature and building a greener future through simple environmental activities.
